# ESP32

O **ESP32** é um microcontrolador poderoso da Espressif com WiFi e Bluetooth integrados, ideal para projetos IoT.

## 🔧 Especificações Técnicas

- **Microcontrolador:** Xtensa dual-core 32-bit LX6
- **Tensão de Operação:** 3.3V
- **Clock:** até 240 MHz
- **Memória Flash:** 4 MB
- **SRAM:** 520 KB
- **WiFi:** 802.11 b/g/n
- **Bluetooth:** v4.2 BR/EDR e BLE
- **Pinos I/O:** 34
