# Arduino (ATmega328P)

O **Arduino** é uma plataforma de prototipagem eletrônica **open-source** baseada em hardware e software fáceis de usar.

## 🔧 Especificações Técnicas

- **Microcontrolador:** ATmega328P
- **Tensão de Operação:** 5V
- **Clock:** 16 MHz
- **Memória Flash:** 32 KB (0.5 KB usado pelo bootloader)
- **SRAM:** 2 KB
- **EEPROM:** 1 KB
- **Pinos I/O Digitais:** 14 (6 PWM)
- **Pinos Analógicos:** 6
